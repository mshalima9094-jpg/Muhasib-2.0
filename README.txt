মুহাসিব — Cloudflare সংস্করণ (ফ্রি প্ল্যানে চলে)
================================================

এতে কী আছে
-----------
• ইউজার মোবাইল নাম্বার অথবা জিমেইল + পাসওয়ার্ড দিয়ে রেজিস্ট্রেশন করে → "অনুমোদনের অপেক্ষায়" স্ক্রিন।
• অ্যাডমিন (আপনি) অ্যাপের ভেতরে মেনু → 🛡️ অ্যাডমিন প্যানেল থেকে অনুমোদন/বাতিল/ব্লক/পাসওয়ার্ড রিসেট/
  ডেটা ডাউনলোড/মুছে ফেলা করেন। অনুমোদন না পাওয়া পর্যন্ত অ্যাপের কোডই ইউজারের কাছে যায় না।
• সব ডেটা Cloudflare D1 ডাটাবেসে জমা হয় (রিস্টার্টে মুছে যাওয়ার ভয় নেই)।
• অ্যাপ অফলাইনে চলে; ইন্টারনেট এলে নিজে থেকে সিঙ্ক হয়; নতুন ফোনে লগইন করলে ডেটা নেমে আসে।

ফোল্ডারে কী আছে
----------------
wrangler.toml     কনফিগ (এখানে শুধু D1-এর database_id বসাতে হবে)
schema.sql        ডাটাবেসের টেবিল (একবার চালাতে হবে)
src/worker.js     সার্ভারের কোড
assets/           অ্যাপ (app.html), লগইন পেজ, সার্ভিস ওয়ার্কার, আইকন
                  ※ app.html সরাসরি খোলা যায় না — শুধু অনুমোদিত ইউজারকে ওয়ার্কার দেয়।

══════════ পদ্ধতি ক: কম্পিউটার থেকে কমান্ডে (সবচেয়ে সহজ ও নির্ভরযোগ্য) ══════════
আগে Node.js (18+) ইনস্টল করুন এবং https://dash.cloudflare.com-এ ফ্রি অ্যাকাউন্ট খুলুন।
ফোল্ডারের ভেতরে টার্মিনাল খুলে এক এক করে:

 ১) npm install
 ২) npx wrangler login                         (ব্রাউজারে Cloudflare-এ অনুমতি দিন)
 ৩) npx wrangler d1 create muhasib             → আউটপুটে database_id পাবেন
      সেই আইডিটা wrangler.toml-এর  database_id = "..."  এর জায়গায় বসান।
 ৪) npx wrangler d1 execute muhasib --remote --file=schema.sql      (টেবিল তৈরি)
 ৫) npx wrangler secret put ADMIN_ID           → আপনার মোবাইল নাম্বার বা জিমেইল লিখুন
    npx wrangler secret put ADMIN_PASSWORD     → আপনার শক্ত পাসওয়ার্ড (কমপক্ষে ৬ অক্ষর)
    (ঐচ্ছিক) npx wrangler secret put TELEGRAM_BOT_TOKEN
             npx wrangler secret put TELEGRAM_CHAT_ID
 ৬) npx wrangler deploy
    শেষে  https://muhasib.<আপনার-সাবডোমেইন>.workers.dev  লিংক পাবেন।

 ৭) লিংক খুলে ADMIN_ID ও ADMIN_PASSWORD দিয়ে লগইন করুন — আপনি অ্যাডমিন।
    ফোনে Chrome → ⋮ → Install app।

══════════ পদ্ধতি খ: GitHub থেকে অটো-ডিপ্লয় ══════════
 ১) এই ফোল্ডারটা একটা GitHub রিপোজিটরিতে তুলুন (প্রাইভেট রাখাই ভালো)।
 ২) Cloudflare ড্যাশবোর্ড → Storage & Databases → D1 → Create database → নাম: muhasib
      তৈরির পর "Console" ট্যাবে schema.sql-এর পুরো লেখা পেস্ট করে Execute চাপুন।
      database_id কপি করে wrangler.toml-এ বসিয়ে GitHub-এ পুশ করুন।
 ৩) ড্যাশবোর্ড → Workers & Pages → Create → "Import a repository" → আপনার রিপোজিটরি বাছুন।
      Deploy command:  npx wrangler deploy      (Build command ফাঁকা রাখুন)
 ৪) ডিপ্লয়ের পর ওয়ার্কার → Settings → Variables and Secrets → Add (ধরন: Secret):
      ADMIN_ID, ADMIN_PASSWORD   (ঐচ্ছিক: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID)
    সেভ করে আবার ডিপ্লয় করুন (বা "Deploy" চাপুন)।
 এরপর থেকে GitHub-এ কোড পুশ করলেই অ্যাপ আপডেট হবে।

নিজের ডোমেইন: ওয়ার্কার → Settings → Domains & Routes → Add → Custom domain।

অ্যাডমিনের কাজ
---------------
মেনু (নিচের বারের ⋮) → 🛡️ অ্যাডমিন প্যানেল:
  অপেক্ষমান → ✅ অনুমোদন / ❌ বাতিল
  অনুমোদিত  → 🚫 ব্লক / 🔑 পাসওয়ার্ড রিসেট / ⬇ ডেটা ডাউনলোড / 🗑 মুছুন
ব্লক বা বাতিল করলে সঙ্গে সঙ্গে তার লগইন সেশন শেষ; অনলাইনে এলেই তার অ্যাপ লক হয়।
অফলাইনে থাকা ফোনে অ্যাপ ততক্ষণ চলে যতক্ষণ না সে অনলাইনে আসে।

ফ্রি প্ল্যানের সীমা (জানা দরকার)
---------------------------------
• Workers: দিনে ১,০০,০০০ রিকোয়েস্ট। অ্যাপ খোলা থাকলে প্রতি ১ মিনিটে একবার সিঙ্ক চেক হয়,
  তাই একজন ইউজার সারাদিন অ্যাপ খুলে রাখলে দিনে ~১৫০০ রিকোয়েস্ট লাগে — কয়েক ডজন ইউজারের জন্য যথেষ্ট।
• D1: প্রতি দিন ৫০ লক্ষ রিড / ১ লক্ষ রাইট; মোট ৫ GB — এই অ্যাপের জন্য অনেক বেশি।
• প্রতি ইউজারের ডেটার সীমা ২৫ MB (নোটে বড় ছবি দিলে এটা দ্রুত ভরতে পারে)।
• ⚠️ ফ্রি প্ল্যানে প্রতি রিকোয়েস্টে CPU সময় ১০ মিলিসেকেন্ড। পাসওয়ার্ড হ্যাশ (লগইন/রেজিস্ট্রেশনে)
  সবচেয়ে ভারী কাজ। wrangler.toml-এ PBKDF2_ITER = "60000" দেওয়া আছে। যদি লগইনের সময় "Error 1102"
  / "exceeded CPU" দেখেন তাহলে সংখ্যাটা কমিয়ে "30000" করে আবার ডিপ্লয় করুন
  (নতুন পাসওয়ার্ড/ইউজারে কার্যকর হবে)। পেইড প্ল্যানে ১০০০০০ দিতে পারেন।

ব্যাকআপ
--------
• ইউজার নিজে: সেটিংস → ⬇ সার্ভার ব্যাকআপ ডাউনলোড।
• অ্যাডমিন: প্যানেল থেকে যেকোনো ইউজারের ডেটা ডাউনলোড।
• পুরো ডাটাবেস: npx wrangler d1 export muhasib --remote --output=backup.sql

নিরাপত্তা ও সীমা
-----------------
• পাসওয়ার্ড PBKDF2-SHA256 দিয়ে হ্যাশ করা; ভুল চেষ্টার সীমা আছে; সেশন HttpOnly+Secure কুকিতে।
• মোবাইল/ইমেইলে OTP নেই — অ্যাডমিন অনুমোদনই যাচাই। পাসওয়ার্ড ভুললে অ্যাডমিন রিসেট করে দেবেন।
• সিঙ্ক "সর্বশেষ পরিবর্তন জেতে" পদ্ধতিতে (ডেটার প্রতিটি অংশ আলাদা)। দুই ফোনে একই অংশ একই সময়ে
  অফলাইনে বদলালে যেটা পরে সিঙ্ক হবে সেটা টিকবে।
• এক ফোনে অন্য ইউজার লগইন করলে আগের ইউজারের স্থানীয় ডেটা মুছে যায় (লগ আউটের সময় অ্যাপ আগে সিঙ্ক করে নেয়)।

পরীক্ষা সম্পর্কে সৎ কথা
------------------------
এই কোড আমার পরীক্ষার পরিবেশে D1-এর বদলে SQLite দিয়ে চালিয়ে দেখা হয়েছে (রেজিস্ট্রেশন, অনুমোদন, সিঙ্ক,
অফলাইন, ব্লক, বড় ডেটা ভাগ করে জমা — সব পাস)। তবে আসল Cloudflare-এ আমি ডিপ্লয় করে দেখিনি। প্রথম
ডিপ্লয়ে কিছু আটকালে (যেমন database_id, secrets, schema চালানো) ওয়ার্কারের Logs ট্যাবের এরর আমাকে পাঠান।
